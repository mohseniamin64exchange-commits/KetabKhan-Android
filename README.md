# کتاب‌خوان (Ketabkhan Reader)

اپلیکیشن بومی و کاملاً آفلاین کتاب‌خوان فارسی با تمرکز بر رابط کاربری تمیز بر پایه‌ی Jetpack Compose و Material Design 3، چیدمان راست‌به‌چپ (RTL) و ذخیره‌سازی محلی داده‌ها.

## ویژگی‌ها و معماری
- **کاملاً آفلاین و محلی (Offline-First):** بدون وابستگی به اینترنت، سرویس‌های ابری یا کلیدهای دسترسی خارجی.
- **رابط کاربری مدرن:** طراحی‌شده با Jetpack Compose بر اساس استاندارد Material 3 و پشتیبانی کامل از زبان فارسی و چیدمان راست‌به‌چپ (RTL).
- **پایگاه‌داده محلی (Room Database):** ذخیره‌سازی امن و ماندگار کتاب‌ها، فصل‌ها، نشانک‌ها و وضعیت مطالعه.
- **تنظیمات مطالعه (DataStore Preferences):** ذخیره‌سازی ترجیحات کاربر شامل اندازه قلم، فاصله خطوط، فونت و پوسته‌های مطالعه (روشن، سپیا، شب).
- **زیرساخت پردازش پس‌زمینه (WorkManager):** معماری استاندارد و آماده‌سازی زیرساخت برای پردازش‌های سنگین فایل‌ها در پس‌زمینه (موتور تبدیل در مراحل بعد پیاده‌سازی خواهد شد).
- **پشتیبانی از فرمت کتاب اختصاصی (`.bookapp`):** دارای Intent Filter برای دریافت امن بسته کتاب از طریق برنامه‌های مدیریت فایل و هدایت به پیش‌نمایش.

## پکیج و شناسه برنامه
- **Application ID / Namespace:** `com.ketabkhan.reader`
- **SDK Target / Compile:** Android API 36 (حداقل Android API 24)

## وضعیت قابلیت‌ها
- **کتابخانه و مطالعه آفلاین:** فعال و متصل به Room Database و DataStore.
- **موتور تبدیل PDF و تولید بسته `.bookapp`:** در حال توسعه (بدون شبیه‌سازی یا درصد پیشرفت فیک).
- **پشتیبان‌گیری و بازیابی اطلاعات:** در حال توسعه.

## اجرای پروژه و تست‌ها
برای کامپایل و اجرای تست‌های واحد از Gradle Wrapper استفاده کنید:

**در محیط‌های لینوکس و مک (Linux / macOS):**
```bash
./gradlew assembleDebug
./gradlew :app:testDebugUnitTest
```

**در محیط ویندوز (Windows):**
```cmd
gradlew.bat assembleDebug
gradlew.bat :app:testDebugUnitTest
```
